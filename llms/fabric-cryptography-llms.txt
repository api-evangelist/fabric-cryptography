# Fabric Cryptography

> Fabric Cryptography (legal entity Fabric of Truth, Inc., Santa Clara, California,
> founded 2022) designs the Verifiable Processing Unit (VPU) — a custom silicon chip
> whose instruction set targets the mathematical primitives of modern cryptography,
> pairing GPU-style programmability with ASIC-class performance. Fabric publishes no
> public API, developer portal, SDK or machine-readable specification.

## Products

- FC 1000 — the VPU chip: ultra-wide vector lanes, 40 tiles, on-chip multi-core RISC-V
  for native witness generation, high-bandwidth unified memory.
- VPU 8060 ("Bit Smasher") — accelerator card carrying three FC 1000 chips, ~1 TB/s of
  memory bandwidth to 30 GB of memory.
- "Byte Smasher" — server chassis carrying up to eight VPU 8060 cards.
- Software — an LLVM-based compiler and a reconfigurable library of cryptographic
  primitives targeting plonky2, plonky3, GKR, halo2, Jolt/Lasso, Nova and TFHE. A cloud
  offering is described on the website as a future way to reach the hardware.
